# Data Retention Policy

This document defines what WHAXON stores during an engagement, for how long, and how it is deleted. It is written for solo operators and small teams to align with the French ANSSI PASSI requirements and the OWASP Automated Threat Handbook (APTS) data handling guidelines.

## 1. What is stored

WHAXON stores all engagement data locally in the `data/` directory (or the `--data` path provided at runtime). No target data is sent to a cloud service by default.

| Data type | Location | Purpose |
| --- | --- | --- |
| Target and scope | `data/scope.json` | Authorization boundary |
| Findings and evidence | `data/whaxon.db` (SQLite) | Verification and reporting |
| Raw tool output | `data/whaxon.db` (lines table) | Reproducibility |
| AI run history | `data/whaxon.db` (ai_runs table) | Audit trail |
| Override log | `data/scope_overrides.log` | Authorization proof |
| Reports | Wherever generated by the operator | Client deliverable |

**Credentials and secrets:** WHAXON does not store credentials. If a tool discovers a credential during a scan, it is recorded as a finding with a `credential_ref` pointer, not as plaintext in the database.

## 2. How long it is retained

The operator defines the retention period for the engagement. WHAXON does not enforce a default deletion. The recommended baseline for PASSI alignment is:

*   **Active engagement:** data retained until the engagement is closed and the report is delivered.
*   **Post-delivery:** evidence retained for **30 days** after report delivery, then deleted.
*   **Audit logs:** retained for **1 year** if the engagement is subject to compliance review.

This is a recommendation, not a technical enforcement. The operator is responsible for scheduling the deletion.

## 3. How it is deleted

WHAXON does not have an automatic deletion command. Deletion is a manual, verifiable operation:

1.  **Close the engagement:** ensure the final report is generated and delivered.
2.  **Archive if required:** if the engagement requires retention, copy `data/whaxon.db` and `data/scope_overrides.log` to a secured archive.
