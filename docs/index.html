WHAXON

One platform. Every layer of security.

A modular, portable cybersecurity testing platform with terminal, desktop, and web interfaces powered by a shared Python core.

View on GitHub Read the docs

Install

git clone https://github.com/andreipath26/WHAXON.git
cd WHAXON
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[tui,gui,web]"

Run

whaxon init             # create data/ with strict default scope
whaxon tui              # terminal UI
whaxon gui              # desktop app
whaxon serve --daemon   # production web server
whaxon web              # dev web server

What it does

  • Catalog of 11 security tools with argument templates
  • 7 tool adapters that produce enriched findings (CVSS, CWE, impact, remediation)
  • Deterministic correlator that finds patterns across findings
  • Pluggable AI layer - Ollama, OpenAI, Anthropic, Google
  • Fail-closed scope enforcement
  • Markdown, HTML, PDF, and JSON reports
  • Metasploit RPC integration and pivot chains

Authorised use only

WHAXON is intended for authorised security testing, defensive security operations, research, and education. Only use it on systems you own or have explicit permission to assess.
