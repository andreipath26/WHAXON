SQL injection on /vulnerabilities/sqli/

127.0.0.1:80 · sqlmap · job 9a52ab3c
Verification
AB
Verified by andreipath 2h ago

Description

The id parameter on /vulnerabilities/sqli/ is vulnerable to boolean-based blind SQL injection. An attacker can extract arbitrary data from the backend database.

Evidence
